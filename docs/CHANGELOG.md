# 변경 이력

## 0.9.0 — 태블릿 조작 · 저장소 이전
- git 저장소로 이전: 원본을 `src/` 15개 파일로 분리, 의존성 없는 번들러, Playwright 테스트 11종, CI·GitHub Pages 배포.
- 터치 모드(자동 감지 + 설정): 탭·두 번 탭·한 손가락 팬·두 손가락 핀치 확대와 이동·길게 누른 뒤 끌어 범위 선택.
- 길게 누르기: 적 → 상성 말풍선, 빈 땅 → 공격 이동, 내 유닛 → 같은 종류, 명령 버튼 → 설명.
- 오른쪽 도구 막대(범위 선택·같은 종류·마을회관·선택 해제·부대 1~4), 전체 화면 버튼.
- 터치 건설은 위치를 고른 뒤 "짓기"로 확정. 큰 버튼, 터치용 안내 문구, 세로·가로 레이아웃.

## 0.8.0 — 완성도
- 목표 안내 10단계, 반복 생산, 새 일꾼 자동 배치, 쉬는 일꾼 알림.
- 부족 색 원판, 피격 번쩍임, 피해 숫자, 상성 툴팁, 태세(공격적·방어적·제자리), 반격 개선.
- 결과 리포트: 군대·일꾼·자원 그래프와 부족별 기록 표.
- 밸런스: 궁수·장궁병 보병 상대 +2 (헤드리스 아레나 15쌍 × 4회 검증).
