# 설계 메모

## 규칙
- 승리: 다른 편 부족의 마을회관을 모두 파괴. 패배: 내 마을회관이 모두 무너짐.
- 인구 한도 부족당 최대 75. 시대: 암흑 → 봉건 → 성주.

## 구조
- **시뮬레이션 좌표:** 직교 타일 공간(타일 1칸 = `T` = 32px). 렌더링만 아이소메트릭(64×32 마름모)으로 투영합니다 (`isoT`, `isoW`, 역변환 `screenToWorld`).
- **맵:** `setMap()`이 크기에 맞춰 A* 배열, 안개, 미니맵 이미지를 다시 할당합니다. 지형은 512px 청크로 지연 베이킹하고 LRU(44개)로 캐시합니다.
- **길찾기:** A*. 성문은 주인·동맹만 통과(`PO`). 도달 불가 목표는 `o.unr`에 기억해 반복 탐색을 막고, 재탐색 간격은 거리에 비례합니다.
- **유닛 간격:** 공간 해시 기반 분리. 밀어내는 힘은 프레임 시간에 비례해 상한을 둡니다.
- **AI:** 부족마다 `G.ais[o]`, 난이도 `G.aiDiff[o]`. 편 판정은 `G.team`(혼자 = 100+i)과 `ally`/`foe`.
- **저장:** localStorage(자동 + 3칸)와 저장 코드. 이전 버전 저장 코드를 계속 불러올 수 있어야 하며 `tests/saves.test.mjs`로 확인합니다.
- **입력:** 마우스·키보드와 터치를 모두 처리합니다. 터치 모드는 `body.touch` 클래스로 켜지고, `pointer:coarse` 감지 또는 첫 터치 입력 시 자동으로 전환됩니다(설정 `dawn.touch`: auto/on/off).

## 문명
- `CIV`(00-data.js): 보너스 설명, 고유 유닛(`uu`)과 훈련 건물(`uuAt`). `trainOf(b)`가 건물별 훈련 목록에 고유 유닛을 붙임.
- 보너스 적용 위치: 시작 시 `applyCivStart`(사거리·채집·농장 → P.m, 저장에 포함), `spawnUnit`(기병 체력), `placeBld`(건물 체력), `calcDmg`(건물 화살), `updBld`(생산 시간), 교역 수익·시장 시세.
- 이전 저장(civ 없음)은 문명 없이 그대로 불러옴.

## AI
- `aiSense`: 자기 유닛·건물 시야(los+1) 안의 적만 인식. 본 적 건물 id를 `ai.kb`에 기억(파괴되면 지움), 본 병종 수는 `ai.seen`에 서서히 감쇠하며 기억. 같은 팀 AI끼리 `kb` 공유.
- 정찰(`aiScout`): 12칸 격자를 가까운 미방문 칸부터 방문, 체력 35% 아래면 귀환. 적 마을회관을 다 찾으면 정찰 종료.
- 습격(`aiRaid`, 보통·어려움): 기병 3기 이상이 쉬고 있으면 알려진 자원 창고로 보내 일꾼을 노림. 체력 절반 이하·80초 경과 시 귀환.
- 공격(`aiLaunch`/`aiWatchAttack`): 알려진 마을회관 우선, 모르면 먼 미탐색 칸으로 수색 진군. 10명 이상이면 40%를 측면 지점으로 우회. 전투 중 아군 전력(체력×공격/속도)이 적 유닛+방어 건물 전력에 크게 밀리면 후퇴, 50초 뒤 재공격. 같은 팀 AI에게 목표를 알려 합류(`ai.join`).
- 캠페인용 플래그: `ai.noWave`(공격·습격 안 함), `ai.armyCap`(군대 상한).

## 캠페인
- `SCN`(13-campaign.js): 임무마다 `opt`(newGame 옵션), `setup`, `goals`, `tick`, `check`(win/실패 이유), `onKill`, `limit`(제한 시간), `noTc`(마을회관 없이 시작).
- 진행 상태 `G.scn`은 저장 코드에 포함. 완료 기록은 localStorage `dawn.campaign`.

## PWA
- `src/manifest.webmanifest`, `src/sw.js`(빌드 시 해시로 캐시 이름 지정), `src/icons/`(`scripts/make-icons.mjs`로 생성).
- 서비스 워커: 페이지는 네트워크 우선(오프라인이면 캐시), 아이콘·폰트는 캐시 우선. http(s)로 열 때만 등록되고, 아티팩트 빌드에는 포함되지 않음.

## 밸런스 (헤드리스 아레나, 동일 자원 약 1200, 15쌍 × 4회)
- 결과 상성: 검사 > 창병 > 기병(경기병·기사) > 궁수 > 보병.
- 고유 유닛: 궁기병은 보병·궁수에 강하고 창병·기병에 약함 / 척후병은 궁수·장궁병 전용 / 방패병은 궁수·창병에 강하고 검사·기병에 약함 / 낙타 기병은 기병·궁수에 강하고 보병에 약함 / 투창병은 값싼 대기병.
- 기사는 창병에게만 약한 고급 유닛, 장궁병은 기병에 약함.
- 상성 툴팁은 비용과 사거리(×1.4)를 반영해 유불리를 판정합니다.
