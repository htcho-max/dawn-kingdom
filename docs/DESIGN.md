# 설계 메모

## 규칙
- 승리: 다른 편 부족의 마을회관을 모두 파괴. 패배: 내 마을회관이 모두 무너짐.
- 인구 한도 부족당 최대 75. 시대: 암흑 → 봉건 → 성주.

## 구조
- **시뮬레이션 좌표:** 직교 타일 공간(타일 1칸 = `T` = 32px). 렌더링만 아이소메트릭(64×32 마름모)으로 투영합니다 (`isoT`, `isoW`, 역변환 `screenToWorld`).
- **맵:** `setMap()`이 크기에 맞춰 A* 배열, 안개, 미니맵 이미지를 다시 할당합니다. 지형은 512px 청크로 지연 베이킹하고 LRU(44개)로 캐시합니다.
- **길찾기:** A*. 성문은 주인·동맹만 통과(`PO`). 도달 불가 목표는 `o.unr`에 기억해 반복 탐색을 막고, 재탐색 간격은 거리에 비례합니다.
- **유닛 간격:** 공간 해시 기반 분리. 밀어내는 힘은 프레임 시간에 비례해 상한을 둡니다.
- **AI:** 부족마다 `G.ais[o]`, 난이도 `G.aiDiff[o]`. 편 판정은 `G.team`(혼자 = 100+i)과 `ally`/`foe`.
- **저장:** localStorage(자동 + 3칸)와 저장 코드. 이전 버전 저장 코드를 계속 불러올 수 있어야 하며 `tests/saves.test.mjs`로 확인합니다.
- **입력:** 마우스·키보드와 터치를 모두 처리합니다. 터치 모드는 `body.touch` 클래스로 켜지고, `pointer:coarse` 감지 또는 첫 터치 입력 시 자동으로 전환됩니다(설정 `dawn.touch`: auto/on/off).

## 밸런스 (헤드리스 아레나, 동일 자원 약 1200, 15쌍 × 4회)
- 결과 상성: 검사 > 창병 > 기병(경기병·기사) > 궁수 > 보병.
- 기사는 창병에게만 약한 고급 유닛, 장궁병은 기병에 약함.
- 상성 툴팁은 비용과 사거리(×1.4)를 반영해 유불리를 판정합니다.
